# FaeWorldArt

Handmade three.js pieces from the Fae world of [neomythism.net](https://neomythism.net).

- **[reverie-objects](reverie-objects/)** · the enchanted objects Reverie is furnished with, and her dollhouse: 37 forms built from geometry in code, no models and no game assets. Twenty modules, one texture, a copy of three.js, and a gallery page. Serve the folder and open `index.html` for the live sheet; the folder's README lists every module and shows how to use them.
